Accounts are made on the control plane with hostseal-server accounts add. There is no sign-up form: an account reaches one fleet, and who is in that fleet is a decision rather than a field. A script does not sign in at all — it carries an API token issued from the account page.

An administrator account is inside HostSeal's threat model. Somebody signed in here can read the fleet and revoke hosts, and still cannot run code on any enrolled machine: what protects the hosts is each one's own policy.toml and a signing key this control plane does not hold.
