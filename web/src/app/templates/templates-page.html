A bootstrap template is applied as root, once, by a host that is enrolling. So a host accepts one only if it carries a signature from a key listed in its own /etc/hostseal/trusted-signers — a file this control plane cannot write and an administrator edits by hand. That is what stops an attacker who owns this control plane from choosing what runs on a new machine.

The signature is made on your own machine. This page sends the template's name and body to hostseal signer running there; it prints the body in its terminal and asks you, your YubiKey signs it when you touch it, and the detached signature comes back. The private key never leaves the YubiKey — not to this browser, not to the control plane, which is the whole reason a host will accept the result.
